## 👨‍💻 Обо мне / About Me

Я backend-разработчик с основным стеком **PHP** и трёхлетним опытом работы системным администратором.

Разрабатываю веб-приложения, административные панели, внутренние корпоративные системы, REST API и сервисы обработки данных. Проектирую архитектуру приложений и базы данных, реализую бизнес-логику, авторизацию, ролевые модели доступа и интеграции.

При разработке использую объектно-ориентированное программирование, принципы SOLID и архитектурный подход MVC. Разделяю приложения на контроллеры, сервисы, репозитории, middleware, валидаторы и представления.

Опыт системного администрирования помогает мне учитывать безопасность, производительность, отказоустойчивость и удобство сопровождения приложений.

I develop web applications, administration panels, internal business systems, REST APIs, and data-processing services. I design application architecture and databases, implement business logic, authentication, role-based access control, and integrations.

I use object-oriented programming, SOLID principles, and the MVC architectural pattern. I structure applications using controllers, services, repositories, middleware, validators, and views.
